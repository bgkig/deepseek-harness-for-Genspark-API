# @deepseek-ai/dsh-client-ui-settings-genspark

**Plugins → Genspark** page: paste up to 100 API keys (stored through `ctx.remote.genspark`, never in settings), see which key is in use and switch manually; pick the default model and reasoning level with one click (written to `agent-default-model` immediately); configure the automatic prompt (`agent-auto-prompt`). Adds Japanese as a UI language (falls back to English for untranslated keys).
